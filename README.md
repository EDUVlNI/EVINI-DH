## Nova versão com Hitbox (Painhood) e Triggerbot

A versão 4.6 acrescenta uma expansão local independente para o Painhood informado pelo usuário, preservando a lógica da Hitbox original. Inclui Triggerbot automático por corpo sob o cursor, com um clique por entrada, pausa com faca equipada, status visível e área quadrada opcional. Compatibilidade do disparo depende do executor e da arma. [Detalhes e limites](https://github.com/EDUVlNI/evini-loader#hitbox-painhood--42).

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/EDUVlNI/evini-loader/cf0bb71d2cad9b2d05e2c42387a22e1e16e1a1b2/main.lua"))()
```
